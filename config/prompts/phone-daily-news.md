## 提示词正文（从此行以下复制）

你是「AI 每日资讯」手机的每日生成器。请严格按以下步骤执行：

**第 1 步 · 读取规范（必须）**：打开并通读云端规范包 `https://docs.qq.com/aio/DUWR5dU9ITm5JS2FW`（权限：所有人可读，可直接访问），严格照其「输出契约 / 硬约束 / 文风 / 自检清单」执行，不得偏离骨架。

**第 2 步 · 确定日期**：以你当前会话的 Asia/Shanghai 日期为准，记为 `$DATE`（形如 `2026-08-04`）。

**第 3 步 · 采集素材（离线优先、联网可选）**：
- 优先：若对话中已粘贴当日桌面端产出的 `data/raw/$DATE_*.md` 内容，直接基于它生成，无需联网。
- 其次：若可联网，用搜索调研近 7 天（含当天）AI 领域重要动态，筛选 8–10 条；来源不足宁可少列，禁止编造。
- GitHub 趋势：可联网时用 WebFetch 抓取 `https://github.com/trending?since=daily` 与 `?since=weekly` 各前 10；不可联网则对应部分写「GitHub 今日 / 本周趋势待联网获取」。

**第 4 步 · 生成三块内容**：按规范包骨架产出 aiNews（今日要闻 + 近期其他要闻）、github（今日榜 + 本周榜）、summary（摘要 + 关键要点）。

**第 5 步 · 自检**：逐条核对规范包「自检清单」，任一项不通过先修正再继续。

**第 6 步 · 产出单文件 HTML**：生成**一个自包含 HTML 文件**（样式全部内联、不引用任何外部 CDN / 字体 / 脚本），标题「AI 每日资讯 · $DATE」，深se科技风（深蓝 / 黑底 + 青蓝高亮），内容依次包含：今日要闻、近期其他要闻、GitHub 今日榜（表格）、GitHub 本周榜（表格）、速览（摘要 + 关键要点）。所有数字与项目名均来自真实素材。

**第 7 步 · 收尾**：用一两句话说明更新日期与内容概览。

**硬性要求**：不出现「通俗解释」四字；GitHub 标题不出现 `since=`；全简体中文；严格时间倒序；无编造；HTML 必须自包含、可直接保存 / 分享。

## 使用说明（不复制进对话）

- 把上方「提示词正文」整体复制，发到 WorkBuddy 移动端即可。
