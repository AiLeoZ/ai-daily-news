# 本地语料目录（离线素材源）

本目录用于 **完全脱离外网** 时，为「AI 每日资讯」提供可引用的本地素材。

## 作用

- 当 `config/runtime.yaml` 的 `mode: offline` 时，`scripts/collect.py --offline`
  会：① 复用 `data/collected/` 中最近一次成功抓取的 `rss_*.json` / `gh_*.json`；
  ② 把本目录下所有 `*.md` 作为"本地语料"并入候选素材。
- 生成阶段（`allow_web_search: false`）**只**基于上述本地素材产出，绝不联网、绝不编造。

## 你应该放什么

- 把你在**有网时**整理好的简报、行业观察、已核实的动态写成 `*.md` 放进来。
- 文件名建议带日期，例如 `2026-08-04-brief.md`，便于按日期排序与过期清理。
- 文档内第一个 `#` 标题会作为素材标题；正文前 200 字内的 `YYYY-MM-DD` 作为发布日期。

## 重要边界

- **不编造**：本目录不是用来"造新闻"的。没有真实素材时，生成器会减少条目数或标注
  「待联网补充」，而不是虚构数字 / 项目名 / 公司。
- 联网运行时（`mode: online`）本目录仍会被并入候选，但优先级低于实时 RSS / GitHub 抓取。

> 一句话：联网正常抓，断网靠缓存 + 本目录。本目录是"离线保险箱"，不是"幻觉发生器"。
