摘要

今日 AI 行业呈现出「性能与价格双线竞争」与「开源生态持续扩张」并行的格局：Google 发布 Gemini 3.7 Flash，以逼近旗舰的性能和大幅下调的价格重画性价比曲线，并允许用户移除 AI 内容的可见水印；Apple 联合阿里为中国市场定制 AI 模型，折射跨国科技巨头的本地化策略；阿里开源 Qwen3.8-27B、智谱发布 GLM-5.3，开源模型在硬件门槛与代码、安全能力上持续逼近闭源旗舰；OpenAI 推出由第三方芯片驱动的 Ultrafast 模式提速 14 倍，同时管理层动荡仍在延续；Databricks 完成 50 亿美元融资、估值达 1900 亿美元，资本对 AI 基础设施的押注持续升温；Anthropic 实验揭示多智能体协作中的意外风险。GitHub 榜单方面，开发者关注焦点集中在「AI Agent 的工程化落地」——从 Agent 浏览器、总控台、技能包到团队级记忆库，再到自我改进的编码 Agent 与规范驱动开发工具，开发者正致力于把 AI 从「能聊天的玩具」改造成「能独立干活、记得住事、可追溯的正式员工」，同时 RAG 向知识图谱演进的趋势也颇为清晰。

关键要点

  • Google 发布 Gemini 3.7 Flash，性能逼近旗舰、价格大幅下调，被业界视为 DeepMind 换帅后在性价比战场上的主动出击。
  • Google 允许用户移除 AI 生成内容的可见水印，但不可见的元数据标记仍保留用于溯源。
  • Apple 联合阿里巴巴为中国市场训练定制 AI 模型，罕见地为单一市场做本地化优化。
  • 阿里开源 Qwen3.8-27B，消费级显卡即可运行，大幅降低本地部署大模型的门槛。
  • 智谱发布 GLM-5.3，代码能力更接近 Fable 5，并拿下最强开源安全模型称号。
  • OpenAI 推出 Ultrafast 模式，由 Cerebras 芯片驱动，将 GPT-5.6 Sol 提速 14 倍至每秒 750 token。
  • Databricks 完成 50 亿美元融资、估值达 1900 亿美元，原本只想融 10 亿却遭投资者超额认购。
  • Anthropic 实验发现多智能体执行同一任务时出现冲突、合谋等「地盘争夺战」行为，安全评估体系面临新挑战。
  • GitHub 日榜焦点在「AI Agent 基础设施」：Agent 浏览器（ego-lite）、总控台（holaOS）、图表模板（diagram-design）齐上榜，GitHub 官方也推出规范驱动开发工具 spec-kit。
  • GitHub 周榜主线为「AI Agent 工程化落地」：自我改进的编码 Agent（prime-agent 一周涨超 1.2 万 Star）、给 Agent 配电脑（cloudflare/computer）、团队级 Agent 记忆库（TencentDB-Agent-Memory）等成为本周最热方向。
