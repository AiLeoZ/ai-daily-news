1. OpenAI 给 10 亿免费用户换上 GPT-5.6：无限文本对话全面开放（2026-08-09）

OpenAI 宣布将 GPT-5.6 全面推向免费用户，覆盖约 10 亿用户。免费版和 Go 版用户将获得无限文本对话额度，并新增"思考"按钮用于处理复杂查询。此前 ChatGPT 免费用户在使用时会受到对话次数限制，此次调整意味着主流大模型的能力门槛进一步拉平。同时，OpenAI 还升级了 GPT-5.6 Sol 的准确性与一致性，并扩大 GPT-5.6 Luna 的免费访问范围。

  • 为什么关注：这是头部模型厂商首次将旗舰级模型以无限额度开放给全部免费用户，直接改写了大模型免费与付费的边界。
  • 注解：以前用免费版 ChatGPT 聊到一定次数就被"请升级"，现在相当于一家餐厅把招牌菜从"会员专享"改成"人人随便吃"。你写邮件、查资料、问问题，都不用再掐着次数省着用了。

2. Claude Code 的 Auto 模式默认开启：Anthropic 让 AI 编程更少人工干预（2026-08-09）

Anthropic 宣布将 Claude Code 的 Auto 模式设为默认开启。该模式允许 AI 在编程过程中自主执行更多操作，减少人类开发者的逐行确认与监督。这意味着使用 Claude Code 编程时，AI 将承担更多连续性的开发任务，人类只需在关键节点把关。

  • 为什么关注：AI 编程工具从"人指挥、AI 执行"加速滑向"AI 自主干、人审核"，开发方式的范式转变正在提速。
  • 注解：以前用 AI 写代码，像你开车时每走一段都要问副驾"这条路对吗"；现在 Auto 模式等于副驾自己掌舵开完大半程，只在路口才问你一声。对程序员来说，重复劳动会明显减少，但"把关"的责任也更重了。

  • 为什么关注：AI 的算力狂飙正在直接转化为电力消耗与碳排放，科技巨头的"绿色承诺"面临现实拷问。
  • 注解：AI 越聪明，背后"吃"的电越多。就像你家空调开得越猛电费越高，亚马逊建的这个"超级空调"（数据中心）太耗电，得专门给它盖个发电厂，但排出的废气可能成为全美最大的污染源之一。这提醒我们：AI 的便利是有环境代价的。

7. Cloudflare 发布 Kitesurf：为 AI Agent 打造的云托管浏览器（2026-08-07）

Cloudflare 推出 Kitesurf，一款专为 AI Agent 而非人类设计的云托管浏览器。相比 Chromium，它在常见自动化任务中消耗更少的计算资源，帮助开发者更高效地构建基于浏览器的 AI Agent。

  • 为什么关注：基础设施厂商开始为 AI Agent 专门打造工具，意味着 Agent 将更顺畅地"使用"互联网，而不仅是调用 API。
  • 注解：AI Agent（能自己干活的 AI）以后要替你上网订票、比价、填表，总得有个"浏览器"让它操作。Kitesurf 就是专门给 AI 用的浏览器，比普通浏览器更轻快。相当于给 AI 配了一辆专用小汽车，而不是让它挤你日常开的公交。
