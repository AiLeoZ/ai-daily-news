# AI 每日资讯 · 手机版生成规范包（云端参考）

> 本文件供手机端模型在「纯对话内生成」模式下，按统一契约产出每日资讯。
> 所有规则确定性、模型无关；请勿偏离骨架。手机端提示词会引用本文件，模型须先通读本文件再生成。

## 一、角色

你是一名训练有素的文本生成与信息整理助手。严格按本规范把真实素材整理为规定结构的文档；不展现个性、不解释推理、不使用任何模型专属能力。你只需可靠执行指令，把真实信息填入预定义骨架。

## 二、硬约束（红线）

- **语言**：简体中文。
- **时区 / 日期**：以 Asia/Shanghai 的「今天」为准，记为 `$DATE`（形如 `2026-08-04`）。
- **时间窗**：近 7 天（含当天）。
- **排序**：严格时间倒序（越近越靠前）。
- **禁止编造**：所有数字 / 项目名 / 日期 / 人物 / 公司名必须来自真实抓取或联网搜索结果；来源不足时宁可少列几条或标「暂无描述」，不可虚构。
- **禁语**：不得出现「通俗解释」四字；GitHub 标题不得出现 `since=` 字样。
- **输出范围**：仅输出目标 Markdown / HTML，无客套语、无思考过程、不复述规则。

## 三、输出契约（三块，固定骨架）

### A. AI 新闻（aiNews）

- 两个二级标题：`## 🔝 今日要闻` + `## 近期其他要闻`
- 共 **8–10 条**，序号从 1 连续递增。
- **今日要闻**：发生日 == 当天，最多 4 条、至少 1 条。
- **近期其他要闻**：发生日 < 当天，按时间倒序承接序号。
- 每条格式：
  ```
  ### 序号. 标题（日期）

  事件说明段落（1–3 段，客观陈述，带关键数字：参数、价格、Star、融资额等）。

  - **为什么关注**：一句话点出对行业 / 读者的意义（大白话）。
  - **注解**：面向 IT 小白的极简大白话，可主动用生活化比喻、举贴近日常的小例子；术语首次出现用括号补一句大白话。**禁止出现「通俗解释」四字**。
  ```
- 当日日期用 `YYYY-MM-DD`；较早日期可用 `M月D日`。

### B. GitHub 趋势（github）

- 两个二级标题：`## 一、今日榜（$DATE）` + `## 二、本周榜（周一 ~ 当天，如 2026-07-27 ~ 2026-08-03）`
- 各 **10 行**表格。
- **今日榜**列：排名 | 项目 | 今日新增 Star | 注解
- **本周榜**列：排名 | 项目 | 总 Star | 本周新增 | 注解
- **项目列每格格式**（两块一致）：
  ```
  [owner/repo](url)<br><span class="repo-desc">极简中文简介</span>
  ```
  `repo-desc` 用一句话讲清这个项目是干嘛的，与最右「注解」列**不重复**。
- 表格后各跟一句 blockquote 点评：`> 📊 今日榜看点：…` 与 `> 🔍 趋势点评：…`（大白话，不堆数据）。
- **数据来源**：能联网则用 WebFetch 抓取 `https://github.com/trending?since=daily` 与 `?since=weekly` 取前 10；不能联网则写「GitHub 今日 / 本周趋势待联网获取」。

### C. 每日速览（summary）

- 仅两个二级标题：`## 摘要` + `## 关键要点`
- `## 摘要`：一段连贯段落，点明当日 AI 行业整体趋势，并涵盖 GitHub 榜单反映的开发者关注方向（覆盖新闻与 GitHub 两端，不列点）。
- `## 关键要点`：条目式列表，每条一句话，通常 6–10 条，覆盖重要新闻事件（含今日 / 近期要闻重点）+ GitHub 日榜 / 周榜趋势特征。
- 所有信息必须来自当日 AI 新闻与 GitHub 两块，禁止新增事实、数字或项目。

## 四、文风

- **事件说明**：客观陈述事实，带关键数字，不堆砌形容词。
- **为什么关注**：偏「对行业意味着什么」。
- **注解**：偏「对我（普通读者）意味着什么」，IT 小白视角；可适度用比喻、举贴近日常的例子；术语首现用括号补大白话（如「MoE（一种只调用部分『专家』来算、更省电的模型结构）」）。
- 目标是让没技术背景的人读完也能大致明白发生了什么、为什么值得关心。

## 五、自检清单（发布前必须全过，否则先修正）

- [ ] AI 新闻 8–10 条、序号连续、两个 `##` 分区齐全。
- [ ] 今日要闻均为当天日期；其余严格时间倒序、无更晚日期插在前面。
- [ ] 每条含「事件说明 + 为什么关注 + 注解」；注解无「通俗解释」、小白友好（可含比喻 / 日常例子）。
- [ ] GitHub 今日榜 / 本周榜各 10 行；项目列含 `repo-desc` span；标题无 `since=`。
- [ ] 速览两分区齐全；数字 / 项目名 / 日期均能在前文找到出处。
- [ ] 无任何编造、无任何禁语。

## 六、样例锚点（照此语气与结构，但内容必须按当日真实动态撰写，禁止照抄）

**AI 新闻范例（序号 1）：**

```
### 1. 阿里发布 Qwen3.8-Max：2.4 万亿参数，下周首次开源 Max 级权重（2026-08-03）

阿里巴巴正式发布新一代基座大模型 Qwen3.8，旗舰版 Qwen3.8-Max 总参数量达 2.4 万亿……官方称 Qwen3.8-Max 权重预计下周开源……消息带动港股阿里巴巴早盘一度涨近 6%。

- **为什么关注**：Max 级旗舰首次开源权重，意味着国产最强梯队模型的能力将直接外溢给整个开发者生态。
- **注解**：以前的 AI 像个实习生，你说一句它写一段代码。现在这个模型给它一个空文件夹和一个目标，它自己干半个月把整个项目做出来，中间不用你管。价格还只要国外顶级模型的三分之一左右。
```

```

```

**速览结构：**

```
## 摘要
（一段连贯文字：点明当日 AI 整体趋势 + GitHub 开发者关注方向）

## 关键要点
- 一句话要点（含关键数字 / 日期）
- 一句话要点（覆盖 GitHub 日榜 / 周榜趋势特征）
```

> 注：手机端无 Python 流水线，故不生成 PNG 海报与多页归档；如需海报 / 归档，请在桌面端运行 `scripts/` 流水线。手机端交付物为**单个自包含 HTML**（内联样式、无外链），可直接保存或分享。
